🎮 Tic Tac Toe — Python

A clean and interactive command-line Tic Tac Toe game built with Python.**

A classic **Tic Tac Toe** game where two players compete on a 3×3 board. This project demonstrates core Python concepts such as functions, loops, conditionals, lists, input handling, and game-state management.

✨ Features

* 🎯 Two-player gameplay
* 🖥️ Interactive command-line interface
* 🏆 Automatic win detection
* 🤝 Draw detection
* 🔄 Play again without restarting the program
* 🧹 Clean and beginner-friendly Python code

🛠️ Built With

* **Python 3**
* Lists & Functions
* Loops & Conditional Statements
* User Input & Game Logic

🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/your-username/tic-tac-toe-python.git
cd tic-tac-toe-python
```

2. Run the game

```bash
python tic_tac_toe.py
```

🎮 How to Play

1. Player **X** starts the game.
2. Choose an available position on the board.
3. Player **O** takes the next turn.
4. The first player to get three marks in a row wins.
5. If all positions are filled without a winner, the game ends in a draw.
